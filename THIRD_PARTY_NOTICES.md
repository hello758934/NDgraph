# Third-party components and acknowledgments

NDgraph is an independent experimental graphing app for TI-Nspire CX II CAS devices.

**Ndless** (https://github.com/ndless-nspire/Ndless) provides the native application SDK/runtime. Ndless's README describes most of its source as MPL 1.1, with exceptions licensed separately. NDgraph references Ndless headers and uses its native APIs, but the project does not vendor Ndless source or SDK files. Please follow the applicable licenses of your SDK distribution.

**nSDL** (https://github.com/hoffa/nSDL) provides graphics functions. nSDL is distributed under LGPL-2.1. The source archive does not vendor nSDL source or binary libraries; compile/linking uses the developer's installation.

**TI-Nspire** is a trademark of Texas Instruments. NDgraph is not affiliated with or endorsed by Texas Instruments, Ndless maintainers, or nSDL maintainers.

This repository's MIT license covers the NDgraph project files only, to the extent their contents are subject to copyright. It does not relicense external dependencies.

# NDgraph — Release Notes

NDgraph is an experimental, open-source native graphing project for the TI-Nspire CX II CAS with Ndless. Each release below retains its original download link.

> **Before installing:** Read the [README](README.md). An Ndless source ZIP is **not** a runnable `.tns` file. Only a successfully compiled `.tns` can be transferred to the calculator. Save your work and back up your calculator before testing experimental builds.

---

## [v0.4 — Calculus Mode](https://github.com/hello758934/NDgraph/releases/tag/Release_4)

**NDgraph can do calculus now.** ⚡

A new Calculus mode joins Real and Imaginary, with a larger expression editor for mathematical operations.

**What's new**
- Numerical derivatives and definite integrals
- Finite summations and products
- Expanded math-function support and a larger calculus editor
- Existing Real and Imaginary graphing modes retained

**Downloads**
- [v0.4 ZIP](https://github.com/user-attachments/files/35044484/NDgraphV0.4.zip) — intended as the easy-install archive; verify it contains a compiled `NDgraph.tns` before transferring anything
- [v0.4 source project](https://github.com/user-attachments/files/35044576/NDgraph_v0.4_Windows_Build.zip) — for developers building with TNS Tool Portable

**Heads-up:** Calculus calculations are numerical approximations, not a symbolic CAS. The calculator build remains experimental.

---

## [v0.31 — Graph Explorer Cleanup](https://github.com/hello758934/NDgraph/releases/tag/Release_3)

**More graphs, cleaner controls.** 🔥

NDgraph grows beyond single-equation plotting with graph-management and interface improvements.

**What's new**
- Six equation slots per mode, with separate graph colors and visibility
- Trace, auto-fit, numerical intersections, equation history, and settings
- Full-screen Functions tab using the Catalog key
- Full-screen Help on **H**, with a bottom event log and developer credit

**Download:** [v0.31 source project](https://github.com/user-attachments/files/34992542/NDgraph_v0.31_Windows_Build.zip)

**Installation:** This is a source package. Build it using TNS Tool Portable before transferring the resulting `.tns` file.

---

## [v0.2 — Real and Imaginary Modes](https://github.com/hello758934/NDgraph/releases/tag/Release_2)

**The complex grapher just got real.** ⚡

This release expands the original complex-root project into a two-mode grapher.

**What's new**
- Real mode for Cartesian equations such as `y=x`
- Imaginary mode for complex polynomial roots, parametric curves, and loci
- Additional math functions and a function-status indicator

**Download:** [v0.2 source project](https://github.com/user-attachments/files/34992241/NDgraph_Ndless_Windows_Build.zip)

**Installation:** Source only; compile with TNS Tool Portable.

---

## [v0.1 — The Beginning](https://github.com/hello758934/NDgraph/releases/tag/Release)

**Four dots started it all.** 💀⚡

Originally named **Complex**, this first experiment set out to graph solutions to complex polynomial equations on the TI-Nspire CX II CAS.

**What's included**
- Numerical complex polynomial root solving
- Plotting roots on a complex plane
- Equations like `z^4=1`

**Download:** [Original Complex source project](https://github.com/user-attachments/files/34992020/Complex_Ndless_Windows_Build.zip)

**Installation:** Source only; compile with TNS Tool Portable.

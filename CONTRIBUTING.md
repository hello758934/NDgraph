# Contributing

Issues and pull requests are welcome. Please include reproduction steps, calculator model/OS/Ndless versions, expected behavior, and any compiler output.

For math/parser changes, add or update a host test in `test_*.c`. Do not claim a native build or hardware test succeeded unless you performed it. Keep external libraries and SDK code out of the repository unless their licenses are respected.

By contributing, you agree to license your contributions under this project's MIT license to the extent permitted by law.
